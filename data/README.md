# Данные

Источник из `projects.md` — официальный демонстрационный проект [IBM Telco Customer Churn](https://github.com/IBM/telco-customer-churn-on-icp4d). Перед использованием проверьте актуальные `LICENSE` и условия для набора в репозитории IBM. Готовое решение IBM не копируется, raw-данные здесь не распространяются.

Ожидается CSV с классической схемой Telco, целью `Churn` и необязательным `customerID`. Пустые строки `TotalCharges` трактуются как пропуски и заполняются внутри train-only pipeline.

`make smoke` создаёт детерминированный **синтетический smoke-набор**. В нём нет реальных клиентов, и он не предназначен для заявлений о качестве.
